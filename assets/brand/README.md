# Brand marks

The Sprichst orbit mark from the design system (`project/README.md`, Logo). Source
PNGs, 1024 px:

| File | Use |
| --- | --- |
| `sprichst-orbit-light.png` | Launcher, About, store: ink mark on canvas `#f2eae1`, coral disc |
| `sprichst-orbit-dark.png` | Dark launcher variant and dark in-app use |
| `sprichst-orbit-foreground.png` | Android adaptive-icon foreground (inside the safe zone), transparent |
| `sprichst-orbit-monochrome.png` | Android 13+ themed icon, single ink, transparent |

Do not recolour, outline, rotate or add effects. `scripts/make_app_icons.py`
writes every platform icon from these files. The design-system artifact is the
source of truth for the mark.
